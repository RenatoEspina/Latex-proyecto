\chapter{Regeneración de los diagramas}
\label{anexo:diagramas}

Todos los diagramas de este informe se generaron con \textbf{PlantUML}
\parencite{plantuml_sf} a partir de los archivos fuente versionados en
\texttt{informe/diagramas/fuente/}. Para regenerarlos tras una modificación:

\begin{verbatim}
# Requisitos: plantuml y graphviz
sudo apt-get install -y plantuml graphviz

cd informe/diagramas

# Imágenes PNG (para el documento)
plantuml -charset UTF-8 -tpng -o .. fuente/*.puml

# Imágenes SVG (vectoriales, para lectura en detalle)
plantuml -charset UTF-8 -tsvg -o ../svg fuente/*.puml
\end{verbatim}

Las imágenes PNG utilizadas por este documento se encuentran copiadas en
\texttt{informe/latex/Figuras/diagramas/}; tras regenerarlas es necesario actualizar esa copia
antes de recompilar el informe.
